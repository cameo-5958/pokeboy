# Pokeboy documentation

- [Architecture and data flow](architecture.md) explains the runtime pieces and
  how content reaches the emulator.
- [Repository map](repository-map.md) assigns responsibility to each source
  area and identifies generated or machine-specific files.
- [Local development](local-development.md) contains reproducible setup and
  validation commands for the app, backend, core, and web emulator.
- [Builds, releases, and versions](release-versioning.md) describes app, ROM,
  and mod release identities and the unsigned iOS artifact flow.
- [Game Boy mod ABI](../gameboy/MODS.md) is the detailed `.gbmod` format and
  linker contract.

ROM images are intentionally absent from the repository. Supply only ROMs that
you are permitted to use.
