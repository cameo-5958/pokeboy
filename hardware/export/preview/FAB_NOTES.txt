ORDER STATUS

Board construction
- 0.80 mm finished thickness, four copper layers, ENIG finish.
- Nominal stack: 0.10 mm outer prepreg / 0.44 mm core / 0.10 mm outer prepreg.
- Minimum routed trace 0.10 mm at the display breakout; default signal trace 0.15 mm.
- Minimum copper clearance 0.10 mm; minimum solder-mask web 0.05 mm.
- Through via 0.45 mm finished pad diameter / 0.20 mm drill.

Critical mechanical instruction
- U1 is a direct-mounted 21 x 21 x 2 mm, 1.27 mm-pitch BGA; the former Core1106
  underside aperture is closed.
- Use X-ray inspection for U1 and verify voiding/bridging against IPC-A-610 Class 2.
- A 3.2 mm cavity leaves approximately 1.2 mm nominal allowance above U1.
- Build and measure a first article before committing the display carrier/enclosure.

Assembly and validation
- U1 is OSD3358-1G-ISM (1 GB DDR3L); boot media is J9 microSD 104031-0811.
- U6 is MAX98357AETE+T I2S mono class-D audio; no analog codec line-out is used.
- J1 is Micro-USB data plus charge, not charge-only.
- Battery is a protected 1S LiPo with 10 kohm NTC.
- Validate sustained-load temperature, charger operation, USB data, display timing,
  backlight current, audio, and every control input before enclosing the first article.
- U1 is rendered as its 21 x 21 mm package envelope; generic component bodies
  require the standard KiCad 9 3D model library on the viewing workstation.
